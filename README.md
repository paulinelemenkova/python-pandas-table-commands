# Pandas DataFrame Table Commands with Python

Python script demonstrating pandas DataFrame table operations (loading, indexing, describing and reshaping) on Mariana Trench data. Reusable data-wrangling reference.

## Scripts

- `pandas_table_commands.py`

## Data

- `Tab-Bathy.csv`
- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `mpl_toolkits`, `numpy`, `pandas`, `seaborn`.

```
pip install matplotlib mpl_toolkits numpy pandas seaborn
```
